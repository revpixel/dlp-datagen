DLP Test Data Generator

Synthetic PII, card, health and secret data for testing data loss prevention rules. Checksummed values pass the same validation real DLP engines run, and nothing here belongs to a real person. Data is generated in your browser.

API

The same generator runs as an API, for scripts and automated tests. Up to 10,000 rows per request (2,000 for XLSX, DOCX and PDF). This command matches your current settings:

Endpoints: /api/generate (params fields or preset, rows, format, valid, seed, header, download) and /api/fields for the field list.

All values are synthetic. Valid-mode numbers follow real formats and checksums, so treat output as test data: don't send it to production systems or third parties that don't expect it. Emails use reserved example.* domains.
