/ API reference

No key needed · base URL https://dlp.cyberdynenetwork.com

GET /api/generate

Generates synthetic records and returns them in the requested format. Every parameter is optional: with none, you get 10 rows of the pii preset as JSON.

ParameterValuesDefault
fields Comma-separated field ids, e.g. full_name,email,ssn. Columns follow the order you list. Overrides preset. Ids come from /api/fields. none
preset pii pci phi banking gov secrets. Ignored when fields is set. pii
rows Whole number, 1–10,000. At most 2,000 for xlsx, docx and pdf. 10
format csv json ndjson txt xlsx docx pdf. Lowercase only. json
valid false, 0 or no (any case) returns near-misses: values that look right but fail their checksum. Any other value means valid. Near-misses are made only for fields with "checksum": true. true
seed Any string. The same seed with the same fields, rows and valid returns identical data, in every format. The seed used is always returned in the X-DLP-Seed header. random
header false (exactly) leaves out the header row. Applies to csv and xlsx only. true
download Present with any value (or none) to get Content-Disposition: attachment; filename="dlp-test-data.<ext>". xlsx, docx and pdf are always sent this way. inline

Response

csvtext/csvHeader row of field ids, then one line per record
jsonapplication/jsonArray of objects keyed by field id
ndjsonapplication/x-ndjsonOne JSON object per line; downloads as .jsonl
txttext/plainLabelled records (SSN: …) for keyword-proximity rules
xlsxExcel workbookOne sheet; bold, frozen header row of field labels
docxWord documentLabelled records
pdfPDFLabelled records as real, extractable text

Every response carries X-DLP-Seed and Cache-Control: no-store, and allows any origin (CORS), with X-DLP-Seed readable from browser code.

GET /api/fields

Everything the generator supports, for programmatic discovery: categories, every field (with whether it has a checksum), presets and the fields they contain, formats, and the row limits. No parameters.

/ Examples

Copy, paste, run
  • Defaults: 10 rows of PII as JSON
    curl "https://dlp.cyberdynenetwork.com/api/generate"
  • A preset as CSV
    curl "https://dlp.cyberdynenetwork.com/api/generate?preset=pci&rows=5&format=csv"
  • Pick individual fields, in your column order
    curl "https://dlp.cyberdynenetwork.com/api/generate?fields=full_name,email,ssn&rows=5"
  • Near-misses that should not trigger DLP
    curl "https://dlp.cyberdynenetwork.com/api/generate?preset=pci&rows=5&valid=false"
  • Repeatable: same seed, same data every run
    curl "https://dlp.cyberdynenetwork.com/api/generate?fields=full_name,cc_number&rows=3&seed=regression-1"
  • JSON Lines, one record per line
    curl "https://dlp.cyberdynenetwork.com/api/generate?preset=phi&rows=20&format=ndjson"
  • Save as a file named by the server (dlp-test-data.csv)
    curl -OJ "https://dlp.cyberdynenetwork.com/api/generate?preset=pii&rows=100&format=csv&download"
  • A PDF to test document inspection
    curl "https://dlp.cyberdynenetwork.com/api/generate?preset=phi&rows=20&format=pdf" -o phi.pdf
  • Discover fields, presets and formats
    curl "https://dlp.cyberdynenetwork.com/api/fields"

/ Limits & errors

  • 10,000 rows per request; 2,000 for xlsx, docx and pdf.
  • GET and HEAD. OPTIONS preflight returns 204.
  • No authentication or API key.
  • Invalid requests stop at the first problem found and return JSON: { "error": "…" }.
400Unknown preset: <name>
400Unknown field(s): <ids>
400Choose at least one field.
400rows must be an integer from 1 to 10000
400rows must be at most 2000 for <format>
400format must be one of csv, json, ndjson, txt, xlsx, docx, pdf
404Not found
405Method not allowed

Every value is synthetic. Valid-mode numbers follow real formats and checksums, so treat output as test data and keep it out of production systems. Emails use reserved example.* domains.
